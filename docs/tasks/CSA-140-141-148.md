## Fixed internal contract v1

Authorization dependency authorize({authorization, lessonId, resourceId}) validates Auth user first then invokes service-only csa140_resolve_pdf(p_actor,p_session_id,p_aal,p_lesson,p_resource), using trusted actor/session claims. Returns {state:'preparing',lesson_id,resource_id:null} or {state:'ready',lesson_id,resource_id,bucket,object_path,size_bytes,checksum_sha256}. Denied throws code AUTH_REQUIRED, ACCESS_DENIED, PDF_NOT_FOUND, SERVICE_UNAVAILABLE. No paths exposed in client descriptor.

PDF-content endpoint GET/HEAD accepts exactly query lesson_id UUID, optional resource_id UUID. Without resource_id GET returns JSON descriptor {data:{lesson_id,mode:'proxied_stream',state,resource_id}} (202 preparing,200 ready). With resource_id it serves authenticated bytes; no original fallback, redirects or signed URL. Every request uses authorize. Only a single valid Range; 206/Content-Range/length or 416 after authorization; invalid/multi-range denied. Production enabled=false default. Dependency storage.open({bucket,object_path,start,end,size_bytes}) returns Response whose bytes/header shape are validated. Immutable resource identity bound to actor/asset/policy; HEAD no body; conditional headers never bypass authorization; no 304.

Watermark worker local trusted function consumes original bytes plus backend-trusted display_name, opaque license_id and immutable source digest; output per-page permanent "Licensed to <display name> - <opaque license ID>". No email/phone/NIC. Proposed pinned Python worker inside existing backend tooling; no service or hosted configuration. Fail encrypted/unsafe/unparseable documents and configured size/page bounds closed; preserve original selectable text/geometry; do not claim all accessibility structure retained without validation. Generate separate identity outputs and render mixed rotation/page fixtures. Worker deployment and queue are integration gates, not fabricated operational acceptance.

Database root: new private pdf_derivatives only; service-only resolver validates current session, lesson/course publication, csa117 entitlement and validated linked course_pdf asset. Derivative readiness requires current immutable asset/version/digest and actor-bound policy; pending never returns original. RPC only backend path, no browser execute or private table grants. Worker registration/generation orchestration remains disabled until trusted bounded runtime and CSA139 contract are integrated.
