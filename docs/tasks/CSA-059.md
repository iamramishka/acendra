## Implemented contract

- `profiles`: Auth UUID identity, display name, optional avatar reference/locale,
  creation/update timestamps. No credentials, email duplication or role fields.
  Display names use 1–100 trimmed Unicode characters as an implementation bound
  for review; optional strings cannot be blank. Updates refresh `updated_at` using
  a schema-qualified trigger function with an empty search path and no client EXECUTE.
- `roles`: generated UUIDs, unique constrained approved codes, display names,
  descriptions and creation time. Seeds: student, content_manager, finance_admin,
  super_admin. Guest is not a persisted role; no users are seeded or elevated.
- `user_roles`: beneficiary/role/actor FKs, grant and revocation timestamps,
  optional actors for controlled operator/system provenance. A partial unique
  index prevents two unrevoked grants for one user/role; revoked records can
  coexist with a new grant. Revocation cannot predate the grant or have an actor
  without a timestamp. Beneficiary, role and actor FK lookups are indexed.
- All identity/history FKs use RESTRICT; deleting Auth/profile/role parents
  cannot silently erase grant evidence. A future approved deletion/anonymization
  workflow must reconcile this with retention requirements.
- RLS is enabled without permissive policies; effective table privileges are
  revoked from PUBLIC, anon, authenticated and service_role. This deliberately
  denies client access until CSA-060 and trusted operations until CSA-061 provide
  reviewed narrow capabilities. No public RPC, signup trigger or elevated-role
  metadata mapping is introduced. PostgreSQL owner privileges remain trusted.

Schema timestamps and uniqueness do not implement an immutable audit ledger.
CSA-061 must implement current-role/MFA checks, safe actor derivation, self-role
denial, last-admin protection, controlled bootstrap and audited grant/revocation
operations. Nullable actors are not permission to bypass those controls.
Avatar reference validation/private delivery requires the storage workflow;
this schema only rejects blank references. Course staff is outside this task.
