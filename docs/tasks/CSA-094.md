## Implementation and contract

- Purchaser/order/method association is checked against immutable bank-order terms.
- Receipts reference a validated, available `bank_receipt` uploaded by that purchaser.
  Submitted/reviewed states require a receipt and submission time.
- Active means `awaiting_receipt`, `submitted`, or `under_review`; a partial unique
  index permits one such submission per order. Rejected resubmissions create new rows.
- Terminal reviews require independent reviewer/time; rejection requires a safe
  public reason. Identity, original receipt, submission time and terminal reviews
  cannot be rewritten.
- RLS enabled; all app and service table/function privileges revoked. No broad
  own-row SELECT exposing receipt IDs. Future authorized safe-view API is required.
- Receipt submission never changes an order or enrollment. CSA-096 owns verified
  settlement linkage for approval; financial role/MFA/current permission checks,
  immutable review audit and atomic fulfillment belong to trusted review operations.
