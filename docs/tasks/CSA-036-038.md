## Behavior and acceptance

`Flutter baseline` runs on every PR targeting `dev` or `main`, pushes to those
branches, and manual dispatch. No path filter can silently omit the baseline
on a documentation-only PR. It restores the committed Flutter and npm locks,
rejects format/analyzer failures, executes every Flutter test, builds release
web without backend credentials, and runs the existing isolated Node tooling
regressions. Any failed command fails the job. There are no diagnostic waivers
or `continue-on-error` steps.

Flutter is pinned to stable **3.44.0**, Dart **3.12.0**, matching the repository's
minimums and the locally installed SDK. The official Linux release manifest
lists framework commit `559ffa3f75e7402d65a8def9c28389a9b2e6fe42`:
https://storage.googleapis.com/flutter_infra_release/releases/releases_linux.json
Third-party actions are pinned to reviewed upstream commit IDs. Tokens have
only `contents: read`; checkout does not retain Git credentials. The job uses
no project secrets, service-role keys, production connections or deployment.
Coverage contains synthetic test results and is retained for seven days;
coverage collection does not invent an unapproved percentage requirement.

The independently triggered `Supabase foundations` workflow remains the real
database/service gate for backend paths: migration replay, pgTAP, database
lint, API/loopback/isolation smoke tests and cleanup. It runs Docker only on a
disposable hosted runner. Laptop Docker is not a prerequisite.

This baseline automates existing meaningful suites covering route guards,
authentication failures/state, profile screens, configuration rejection,
theme, responsive layouts and accessibility foundations. Future browser E2E,
payments, media/security suites and production release gates remain governed
by `docs/TESTING.md`; a baseline pass does not certify those features.

## Reproduce without Docker

```sh
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed lib test
flutter analyze --no-pub
flutter test --no-pub --coverage
flutter build web --release --no-pub
npm ci --no-audit --no-fund
npm run tool:test
```

Use Flutter 3.44.0 and Node 22. Test discovery includes all files under `test/`;
no suite is removed to obtain a green baseline. Formatter cleanup is limited
to the 43 existing files identified by a failing pre-change check.
