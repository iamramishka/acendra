## HTTP contract
POST create-course; Authorization Bearer Supabase authenticated token; approved
ACENDRA_ADMIN_ALLOWED_ORIGINS CORS. Auth validates exact token before extracting
subject/session/assurance. Backend resolves current account/role/session on RPC.
Request JSON: request_id UUID, title string1–200 nonblank, slug canonical lowercase
ASCII alphanumeric segments separated by hyphens1–200; optional category_id UUID
or null, short_description string/null, description string/null. Metadata-only
body limit65536 bytes. Unknown fields rejected. Never supply actor, role, price,
status, staff or protected lesson content. Identical request_id+body replay by the
same actor returns its existing course; changed body conflicts. Role/session is
rechecked for retries. Current superadmin uses aal2; contentmanager may use aal1.
Success200: {data:{course_id:UUID,status:"draft"},request_id:UUID}. Errors contain
only {error:{code},request_id} with no internal details:400 INVALID_REQUEST;
401 UNAUTHENTICATED;403 FORBIDDEN/ORIGIN_FORBIDDEN/HEADERS_FORBIDDEN;
404 CATEGORY_NOT_FOUND;409 INVALID_OPERATION/COURSE_CONFLICT;
405 METHOD_NOT_ALLOWED;500 OPERATION_FAILED;503 SERVICE_UNAVAILABLE.
Created rows remain invisible to public catalog until a future authorized publish
workflow; this endpoint does not change publication, price or deliver content.
