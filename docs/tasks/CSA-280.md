## Implementation

- Greeting is independent of enrollments: local-time greeting, trimmed display name and Welcome back remain visible for loading, errors and empty libraries. New students receive an Explore action.
- Feature-local StudentHomeRepository composes existing active-enrollment, com015 summary, published curriculum and csa133 progress reads. It never opens protected content, saves progress or grants access merely to render Home. Invalid/missing summary data is unavailable rather than clamped or replaced with zero.
- Resume selects the most recently opened unfinished course and validates the next unfinished lesson against available curriculum metadata. Its CTA preserves exact course/lesson identity. Completed/unstarted courses do not become fabricated resume candidates.
- Owned-course cards show actual title, description, existing authorized artwork delivery, completion counts/percentage and Continue/Get Started/Review/Open actions as applicable. Two columns at standard mobile size fall back to one column for narrow widths or large text. At most four cards precede View All.
- Recently Accessed lists up to four saved lesson records across enrolled courses, sorted by actual last-opened timestamps and filtered against available curriculum. Video/article/PDF types and saved positive PDF pages are shown; unknown PDF page totals are omitted. Metadata/progress reads run one course at a time for started courses, so request concurrency is bounded; large libraries require more reads under the existing contract.
- A session-aware auto-disposed provider recomputes on sign-out, account changes and refreshed sessions. Loading on refresh/reload replaces prior-session display. Late old-provider results cannot replace current Home.
- Personal learning and discovery have separate loading/error boundaries and public retry copy. Pull-to-refresh reloads both. Real catalog/category IDs drive discovery navigation and filters; latest published courses replace fake featured entries. Runtime providers no longer import dashboard_sample_data.dart, and preview/sample notices/snackbars are removed. That file remains a test/tool fixture only.
- The original bank/payment/content authorization gates and backend authority remain unchanged. A Home route/progress percentage is never treated as an entitlement.
